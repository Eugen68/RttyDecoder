# Taste rapide

## Fereastra principala

| Tasta | Actiune |
|---|---|
| F1 ... F8 | Macro-urile 1..8 |
| Esc | STOP emisie |
| Enter (in campul de emisie) | Trimite textul |
| Ctrl+O | Deschide WAV |
| Ctrl+S | Salveaza textul din terminal |
| Ctrl+Shift+C | Fereastra Contest |
| Alt+F4 | Iesire |

## Fereastra Contest

| Tasta | Actiune |
|---|---|
| Enter | Cu ESM: mesajul potrivit starii (CQ / raport / TU + logare); fara ESM: logare |
| F1 ... F4 | Macro-urile Run sau S&P |
| Esc | STOP emisie |

## Waterfall

| Comanda | Actiune |
|---|---|
| Click | Acord |
| Rotita / Ctrl+rotita | Acord fin 1 Hz / 10 Hz |
| Alt+rotita | Zoom |
| Alt+tragere / butonul din mijloc | Deplasare |
| Shift+click | QSY |

## A-TUNE

| Comanda | Actiune |
|---|---|
| Click | Acord automat + NORM/REV + calculul frecventei pentru emisie |
| Dublu click | QSY: statia pe frecventa corespondentului |

## Indicative

| Comanda | Actiune |
|---|---|
| Click | Copiaza; devine `{CALL}`; merge in formularul Contest |
| Click pe un numar / cuvant (cu Contest deschis) | Preluat in Nr. primit / Schimb primit |
| Dublu click | Pagina pe QRZ.com |
| Click dreapta pe un macro | Editare macro |
